# 1.4.0 使用与升级说明

1. 关闭 Obsidian 中的“渐进式复习”，并备份知识库。
2. 下载 `review-center-1.4.0.zip`，把其中 `review-center` 文件夹内的 6 个文件覆盖到原插件目录。
3. 保留原插件目录中的 `data.json`，并保留知识库内已有的复习数据目录；不要用安装包文件夹整体替换原目录。
4. 重新打开 Obsidian 并启用插件。

升级后，原有笔记、题库、稳定标识、评分、排程和历史保持不变。自动出题默认关闭，不会因升级自动联网；需要使用时，在“设置 → 渐进式复习 → 自动出题”主动配置 API、模型、SecretStorage 密钥、题库位置和提示词。

第一次连接服务时，建议用不含隐私的示例笔记和小批量题目测试。触发生成会把当前原文、已有题目及相关评分表现发送到用户指定的服务；其数据处理规则由服务商决定。插件普通设置只保存 SecretStorage 密钥名称，不保存密钥值。

最低要求 Obsidian 1.13.0。真实第三方提供商、实体移动端和跨设备并发同步不在本次发布验收范围内。
