# 复习中心 0.4.0 测试版：使用与升级

## 安装

解压 `review-center-0.4.0.zip`，将 `review-center/` 放入知识库 `.obsidian/plugins/`。升级时覆盖 `main.js`、`styles.css`、`manifest.json`，保留原 `data.json` 和整个复习数据目录，然后重新启用插件。最低 Obsidian 版本为 1.13.0。

安装包已包含本地计算模块，不需要另外安装 Rust、Node 或联网下载模型。测试数字只存在于隔离测试库，未写入默认配置。

## 主页

1. 选择“笔记”或“卡片”。点击一行选择范围，再点击“开始”。选择父级包含其后代。
2. 点击箭头展开或收起；齿轮打开菜单，不会改变当前选择。名称过长时省略，桌面悬停可看完整标签路径。
3. 蓝色是未学习，红色是学习／重学中，绿色是到期复习，灰色是零。尚未到时间、已暂停、内容待确认或已搁置的项目不计入。
4. 多标签内容可能同时出现在多个分支。父级数量和实际队列按稳定标识去重，所以父级不一定等于子级相加。
5. “继续”恢复本机未完成会话。模式、选择、展开状态和主页滚动位置保存在本机；统计页返回后恢复列表位置。

顶层组保留原有顺序。单标签组直接展示子标签，多标签组展示各个标签分支。内容匹配多个组时仍按最具体标签优先，同级按组顺序归属。统计和热力图在“统计”页面；内容管理、完整备份、恢复及操作记录从插件设置进入。异常在主页显示简短处理入口。

## 复习选项

齿轮的“选项”打开宽弹窗，手机为全屏。插件设置使用同一编辑器。切换对象或关闭弹窗保留本次插件运行期间的草稿，点击“保存”后统一生效；重载插件会丢弃尚未保存的草稿。

- 每个旧组升级为自己的独立预设，原数值不变。笔记和卡片的预设相互独立。
- 子标签默认继承父级预设，也可选择其他预设。“复制为新预设”用于单独调整某组。共用预设的参数变动会作用于所有引用它的组或节点。
- 每日额度按“仅限今日 → 当前节点 → 预设”取值；今日覆盖在本机日期切换后失效。清空节点覆盖或点击旁边重置按钮可恢复继承。
- 每日新内容决定最多开始多少篇／张；每日到期复习决定最多复习多少项，同项当天重复练习不重复扣除同类额度。
- “新内容独立于复习上限”默认开启；“使用顶层组的上限”默认关闭，与原行为一致。
- 目标记忆率越高通常复习越频繁。学习／重学步长用 `1m 10m` 等格式；最大间隔单位为天。

“新内容”“遗忘”“展示顺序”“关联卡搁置”和 FSRS 的复杂项目默认收起。问号显示解释。抽取顺序先决定哪些新内容进入当天额度，再按排列顺序呈现。随机使用会话保存的种子，继续或重启后保持顺序。笔记模式隐藏卡片类型排列和关联卡搁置。

记忆难点默认遗忘阈值为 8，默认仅作项目内部标记；可改为同时暂停。不会给整篇笔记添加难点标签。关联卡仅指同一挖空块的 c1、c2 等，三个搁置开关默认关闭。搁置到次日自动失效，不改排程；撤销评分会恢复由该次评分连带搁置的关联卡。

## 本地优化与重新排程

固定使用 FSRS。电脑端的“优化当前预设”“优化所有预设”“帮我决定”在后台运行，支持取消，全部数据留在本机。至少需要 64 条有效跨日复习记录，并且学习序列需要第一条新学记录；历史不足时提示原因并保留原参数。手机可手动编辑参数和使用已保存的优化结果。

筛选支持以下条件，空格表示同时满足，可用 `-` 排除；不支持的表达式会明确报错：

```text
preset:"预设名称" tag:中医/伤寒 path:资料 -is:suspended
```

默认排除暂停项目。重复事件、撤销评分和重置前的记录不参与优化。计算按项目当前归属的预设收集适用历史。结果展示跨日样本数和优化前后误差；健康检查进一步按时间分段评估。误差更低仅表示对所用历史拟合更好，不保证未来表现。

优化结果只进入草稿，点击保存才生效。“优化所有预设”逐个处理当前笔记或卡片模式的预设，分别显示成功、样本不足或失败。取消、数据不足和计算错误均不修改已保存参数。

“帮我决定”模拟当前预设中这批内容从新学开始的一年，展示不同目标记忆率的平均每日用时和复习项数。采用当前每日新学／复习额度，不设置每日时长上限。缺少用时的旧历史使用官方模拟器的默认用时，界面会显示缺失条数。推荐值以单位记忆效果的时间成本为目标，是估算而非保证。

0.4.0 开始记录前台复习用时。退出、切到其他笔记、切到后台和关闭插件时暂停计时，继续后累加；单次评分最多计 5 分钟。旧历史不会补造用时。

“更改时重新排程”默认关闭，保存参数不会移动已有到期时间。开启后，保存时先展示影响数量和日期样例，再确认、备份、暂停写入并重算。只调整已有完整学习历史、处于复习阶段的项目；缺少历史或已变化的项目保留并报告。重新排程记录保存在 `operations/`，中断后启动时尝试续接，也可从“批量操作记录”继续。

## 全库标签重命名与删除

组菜单的重命名只改组名，删除只移除组配置。子标签菜单会修改整个知识库中的真实标签及子标签，包含未进入复习的笔记；删除标签不会删除笔记。

执行前检查逐文件预览，可展开查看变化、取消个别文件。修改目标标签会使旧预览失效。确认后先备份数据和原笔记，再核对文件内容并写入。代码中的标签样例不处理；属性目标标签已存在时合并去重，正文中相同目标标签也会去重。

预览后被修改、无法解析或写入失败的文件会逐项报告，不覆盖新内容。插件数据目录被排除。成功后同步更新两种模式的标签引用；部分失败或取消时保留旧引用。标签位置变化会重新定位卡片，纯标签修改不改变未变动卡片的稳定标识、排程和历史；如果标签就在卡片正文中，按正常内容变更流程处理。

设置中的“批量操作记录”可查看原文和备份路径，继续未完成操作。已完成文件不会重复写入。因文件内容已变化而失败的项目，应保留现有改动，重新预览后执行。取消的文件不会在续接时被自动选中。

## 备份与兼容

设置和新备份版本为 4，继续读取 v1、v2、v3 备份。从 0.3.0 升级时，旧设置、排程和历史先保存到数据目录的 `exports/pre-options-migration-*.json`。升级不改笔记内容，不重新制卡，不重置学习状态或历史。更早版本仍依次执行原有的标签组和 Callout 迁移保护。

- **完整备份**：包含整个复习数据库和设置；恢复前另存当前备份，再替换复习数据库。
- **范围备份**：齿轮“导出”保存当前模式、所选组／标签及后代的项目、历史和相关组／预设，按标识去重。它不包含原 Markdown 文件，也不包含另一模式的学习进度。
- **范围恢复**：合并缺少的项目和设置。冲突保留本地值，显示冲突清单；不会用范围备份清空其他内容。原笔记仍需存在或另行迁入相同知识库路径。

数据目录迁移仍使用 0.3.0 的备份、复制、校验与续接机制。目录内新增 `operations/`，其中含标签操作原文和重新排程记录，应随其他复习数据一并保留。

## 测试版边界

已在真实 Obsidian 桌面和其 390×844 手机模拟布局中验证。尚未进行实体 iPhone／Android、其他桌面操作系统、第三方主题及多设备同时写入的实机验证。本地优化以小型合成历史完成集成验证，大型历史的耗时和内存占用仍需实际使用反馈。
