# 0.4.0 测试版验证记录

日期：2026-09-03。环境：macOS，真实 Obsidian 1.13.7，独立临时测试知识库。测试没有改动用户正式知识库。

## 自动验证

`npm run check`：20 个测试文件、100 项测试全部通过，TypeScript 检查和生产构建通过。覆盖原 0.3 功能，以及：

- 单／多标签树、子标签边界、自然排序、父级去重、三种数量与未来／搁置排除。
- 预设独立迁移与继承、具体标签参数归属、今日覆盖失效、顶层额度约束、会话随机稳定性。
- 同一挖空块关联卡搁置、撤销、难点标记或暂停、有效用时排除暂停时间。
- 标签前缀修改、属性／正文去重、代码样例排除、预览后变化、失败不写、写入后未记检查点的续接。
- 旧备份 v1–v4 读取、范围导出隔离另一模式、冲突保留本地、不导入冲突历史。
- 重新排程影响计划、默认不重排、先备份、已追加事件不重复、截断检查点回退。

## 真实界面检查

已检查 1180×884 桌面、390×844 Obsidian 手机模拟模式及明暗主题。附图来自实际安装后的界面，数字属于测试资料。

- 手机主页没有横向溢出，三列数量完整保留，名称省略。
- 工具栏、展开和齿轮有效触控区域均至少 44×44 像素。
- 列表独立滚动；滚动到 140 像素后进入统计再返回，仍为 140。
- 手机列表说明底部为 y=750，Obsidian 导航从 y=760 开始，无重叠。
- 手机选项窗口为 390×844，内容宽度 390，无横向溢出；后台优化按钮禁用并有说明。
- 笔记底部四档按钮均为 88.5×54 像素，有红橙绿蓝底色、文字及下次复习间隔。

测试中修复了：原生顶栏导致主页高度溢出、浮动导航遮挡、刷新按钮不足 44 像素、标签执行按钮内部禁用状态未同步，以及 Electron 不支持 Node worker_threads 的运行差异。正式插件使用 Web Worker 中的 WASI 模块，普通 Node 冒烟测试与 Obsidian 内部测试分别执行。
