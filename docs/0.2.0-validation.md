## 实测中修复的问题

- 默认按钮样式覆盖热力图颜色：提高组件样式优先级。
- 手机原生顶栏与内容区域间距不一致：分别适配手机已有顶栏间距及其他移动布局，并修正内容高度。
- 初始扫描前访问恢复会话会消耗队列位置：增加恢复等待状态，开始／继续先完成数据刷新。
- ts-fsrs 5.4.1 的排序调整可能突破最大间隔：对预览与实际排程统一执行最大间隔限制。
- 默认随机种子包含当前时间，导致同次复习的预览波动：改为稳定内容身份与复习次数构成的种子。
