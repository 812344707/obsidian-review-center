# 1.0.1 使用与升级说明

最低要求 Obsidian 1.13.0。内部 ID 保持 `review-center`，升级沿用现有设置、评分与排程。[下载完整安装包](https://github.com/812344707/obsidian-review-center/releases/download/1.0.1/review-center-1.0.1.zip)。

## 本版变化

关闭上次复习的笔记标签页后，再点“开始”会重新获取有效标签页并打开目标笔记；评分栏只在当前复习笔记显示。若仍无法打开，会清理评分栏并提示重试。

在“设置 → 渐进式复习 → 数据与备份”增加“修复知识库”。适用于复习启动异常、移动笔记后路径不正确或复习清单异常。

## 升级步骤

1. 等待知识库同步完成，备份插件目录和复习数据，暂时关闭插件。
2. 将安装包 `review-center/` 内的 6 个程序与许可文件复制到现有 `.obsidian/plugins/review-center/` 内，覆盖同名文件。
3. 保留现有 `data.json` 和复习数据目录，不要替换整个插件文件夹。
4. 重新启用插件，检查版本为 1.0.1，再返回主页开始复习。

从 1.0.0 升级不引入新的数据迁移。从 0.4.6 或更早版本升级，请同时阅读 [1.0.0 升级说明](1.0.0-upgrade.md)。

## 使用“修复知识库”

点击按钮后，插件先保存完整的修复前备份，再重新读取纳入复习的原文，核对路径、标签和卡片索引。完成后显示已核对数量、待核对数量及备份路径。备份位于当前复习数据目录的 `exports/pre-repair-*.json`。

修复保留评分、排程和历史。暂时找不到的原文保留复习记录，等待同步完成后可再次修复以重新连接。修复期间暂停复习计时，防止重复执行及评分、批量处理交叉写入。

如果索引尚未就绪、数据无法读取或备份失败，页面会说明原因。先等待同步或保存完成，再根据提示重试；不要删除复习记录或改写稳定编号绕过错误。此按钮用于本插件的复习数据与索引，不能恢复已经缺失的笔记原文。

详细功能见 [使用手册](user-guide.md)，验证范围见 [验证记录](1.0.1-validation.md)。
