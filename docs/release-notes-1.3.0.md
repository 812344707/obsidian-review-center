# 1.3.0 · 自定义习题页标签

设置 → 习题页新增“习题页标签”。可以从知识库已有标签中选择，也可以输入新的普通或层级标签；保存后只影响以后创建的习题页。

新建习题页时，自定义标签会与来源笔记当时的标签合并并去重。这样既能保留原文分类和原有复习识别范围，也能为所有习题页补充统一的标签，例如 `#习题页` 或 `#医学/练习`。设置留空时继续只复制来源标签，与 1.2.0 及更早版本行为一致。

旧设置升级后自动得到空的习题页标签列表，不修改已有习题页、复习记录、稳定标识、评分、排程或历史。异常的旧存储值会安全回退为空列表，不会阻止插件启动。
