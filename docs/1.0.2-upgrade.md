# 1.0.2 使用与升级说明

最低要求 Obsidian 1.13.0。内部 ID 保持 `review-center`。[下载完整安装包](https://github.com/812344707/obsidian-review-center/releases/download/1.0.2/review-center-1.0.2.zip)。

## 本版变化

填空答案显示时，单段长文字在原句中自然换行；英文连续字符串也会限制在卡片宽度内。包含换行的答案放在独立的“答案”区，保留原始段落、列表、粗体、代码及链接。原句保留空格和提示，同一编号的多个答案按原文顺序显示。

本次修改显示逻辑和样式，不改变卡片识别、稳定编号、内容哈希、评分或排程规则。

## 升级步骤

1. 等待同步完成，备份插件目录和复习数据，暂时关闭插件。
2. 将安装包 `review-center/` 内的 6 个程序与许可文件复制到现有 `.obsidian/plugins/review-center/` 内，覆盖同名文件。
3. 保留已有 `data.json` 和复习数据目录，不要删除整个旧插件目录。
4. 重新启用插件，确认版本为 1.0.2。显示一张长答案填空卡，检查换行和段落格式。

从 1.0.0 或 1.0.1 升级不引入新数据迁移，无需为本次显示修复重新制卡或修复知识库。从更早版本升级，请同时阅读 [1.0.0 升级说明](1.0.0-upgrade.md)。

功能与语法见 [使用手册](user-guide.md)，已测范围见 [验证记录](1.0.2-validation.md)。
