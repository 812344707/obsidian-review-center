# 1.4.1 使用与升级说明

1. 关闭 Obsidian 中的“渐进式复习”，并备份知识库。
2. 下载 `review-center-1.4.1.zip`，把其中 `review-center` 文件夹内的 6 个文件覆盖到原插件目录。
3. 保留原插件目录中的 `data.json`，并保留知识库内已有的复习数据目录；不要用安装包文件夹整体替换原目录。
4. 重新启用插件。首次启动会在知识库创建 `.review-center/settings.json` 设置镜像，不会移动或重建复习数据。

以后每次保存设置，插件会把同一份归一化配置写入 `data.json` 和设置镜像并回读核对。更新器若重建、丢失或回滚插件目录中的主设置，启动会自动恢复较新的有效副本；如果一份副本损坏，会使用另一份，而不是静默回到默认设置。

镜像包含数据目录、复习标签与参数、显示、习题页和自动出题配置，只保存 SecretStorage 密钥名称，不保存 API 密钥值。使用 Obsidian Sync 跨设备同步镜像时，需要开启“同步其他文件类型”，并在启动复习前等待同步完成。

最低要求 Obsidian 1.13.0。跨设备同时修改设置和实体移动端仍不在本次验收范围内。
