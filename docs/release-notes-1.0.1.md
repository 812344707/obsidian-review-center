# 1.0.1 · 启动修复与知识库修复

修复关闭上次复习的笔记标签页后，再点“开始”仍停留在主页、底部却出现评分栏的问题。现在会重新获取有效标签页，确认目标笔记显示后再显示评分栏；打开失败时提示重试。

在 **设置 → 渐进式复习 → 数据与备份** 新增 **修复知识库** 按钮：先自动备份，再重新核对复习标签、原文路径和卡片索引；保留评分与排程，显示进度、结果和备份路径。暂时找不到原文时保留记录，索引未就绪或备份失败时停止并提示处理。

[下载完整安装包](https://github.com/812344707/obsidian-review-center/releases/download/1.0.1/review-center-1.0.1.zip)。最低要求 Obsidian 1.13.0，升级时保留 `data.json` 和复习数据目录。

255 项自动测试通过，并在 Obsidian 1.13.7 中验证修复、关闭标签页后重新开始和进度保留。详细步骤见 [升级说明](1.0.1-upgrade.md)，已测范围及设备限制见 [验证记录](1.0.1-validation.md)。
