# 复习中心 0.4.2 测试版：一个开始入口与分类设置

## 本次变化

主页工具栏调整为“笔记／卡片、统计、开始、刷新、设置”。不再显示单独的“继续”：选择上次未完成的同一模式、复习组和标签分支后点击“开始”，会接着原队列的位置、顺序和答案状态；选择其他范围则按该范围重新建立队列。已评分内容、历史和当天已使用的额度不会被清空。

“设置”直接打开复习中心的插件设置。命令面板新增“复习中心：打开插件设置”，可在 Obsidian“快捷键”中自行绑定。

插件设置分为四页：

- **复习分组**：笔记／卡片组的名称、标签、顺序和批量添加标签。
- **卡片识别**：整篇文章与文章内卡片的识别规则、`[!review]` 示例及识别异常入口。
- **数据与备份**：数据目录迁移、内容与备份管理、批量操作记录。
- **显示**：启动行为和两种热力图。

每日上限、学习步长、展示顺序、FSRS 和关联卡搁置等参数只在主页齿轮菜单的“选项”里编辑。设置页不再重复显示这些参数。不同页面、模式和分组之间切换会保留草稿，点击对应页面的“保存”后生效；未确认的标签输入也会随草稿保留。

## 标签和识别规则

本版沿用标签分组，不增加 YAML 分类属性。新安装默认的笔记组和卡片组均使用 `#review`；已有安装继续使用自己的复习组、根标签和顺序，不会被默认值覆盖。

`#review` 会包含 `#review/伤寒`、`#review/伤寒/第一章` 等子标签，但不会包含 `#review基础`。整篇笔记按笔记复习组的标签纳入，不要求包含复习块；卡片继承来源笔记的标签分类，只在卡片复习组的标签范围内识别 `[!review]`。普通正文和其他类型提示块不会制卡。笔记和卡片的参数、排程及历史保持独立。

卡片类型现固定为 `[!review]`，设置页不再提供额外提示块类型，也不再因保存识别规则而遍历整个知识库。旧设置中的额外类型会被忽略；这些提示块不会再生成卡片。若已有卡片稳定标识仍留在未识别的提示块中，扫描会保留其原进度并列为识别问题，不会静默删除排程。

## 安装与升级

1. 解压 `review-center-0.4.2.zip`。
2. 把其中 `review-center/` 目录放入知识库 `.obsidian/plugins/`，升级时覆盖 `main.js`、`manifest.json` 和 `styles.css`，保留原 `data.json` 与复习数据目录。
3. 重新加载 Obsidian，再打开复习中心。

设置与备份格式仍为版本 4。本次不迁移文章、不修改标签、不重制卡片，也不重新排程。旧会话格式可以直接读取；新保存的本机会话同时保存撤销所需快照，因此重启后同范围点击“开始”仍可撤销最近一次评分。撤销前会核对当前项目修订，数据已经变化时不会覆盖新内容。

这是本地测试版，未发布到 GitHub，也不会自动安装到正式知识库。测试范围和实际界面见同目录验证记录及界面对照图。
