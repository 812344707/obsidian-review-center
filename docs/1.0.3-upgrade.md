# 1.0.3 使用与升级说明

最低要求 Obsidian 1.13.0。内部 ID 保持 `review-center`。[下载完整安装包](https://github.com/812344707/obsidian-review-center/releases/download/1.0.3/review-center-1.0.3.zip)。

## 本版变化

`Extra:` 现在统一表示答后补充。复习正面不会显示该字段；点击“显示答案”后，答案下方只显示补充内容，不显示 `Extra:` 字样。标准 Basic/Cloze、正文 `Q:` / `A:`、正文独立挖空及 `[!review]` 内的问答/挖空均支持这一规则。

补充内容支持 Markdown 文字、链接和图片。补充中的 `{{c1::示例}}` 只作为补充显示，不会生成额外卡片。快速插入的标准问答模板增加了空白 `Extra:` 字段，不需要补充时可留空或删除。

## 升级步骤

1. 等待同步完成，备份插件目录和复习数据，暂时关闭插件。
2. 将安装包 `review-center/` 内的 6 个程序与许可文件复制到现有 `.obsidian/plugins/review-center/` 内，覆盖同名文件。
3. 保留已有 `data.json` 和复习数据目录，不要删除整个旧插件目录。
4. 重新启用插件，确认版本为 1.0.3，然后点击一次“整理数据”。
5. 如“需要处理”出现内容已修改的卡片，先核对答案与补充拆分是否正确；正确时选择保留原进度。

本版提高正文解析版本以清除旧缓存。稳定卡片编号、评分历史和排程会保留；此前被当作答案正文的 `Extra:` 内容会成为内容变更，未经核对不会自动覆盖已接受内容。

功能与语法见 [使用手册](user-guide.md)，已测范围见 [验证记录](1.0.3-validation.md)。
