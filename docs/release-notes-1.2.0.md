# 1.2.0 · 增量整理与时间模板

“整理数据”改为增量读取。插件仍会用 Obsidian 元数据对全库做轻量的标签、路径和来源标识核对，但只读取当前纳入且新增、重新纳入或发生变化的知识点笔记正文；解析规则变化时也会重新读取。首次从旧版升级后，会为已纳入材料补充扫描指纹，后续整理及重启后可跳过未变化正文。

移出复习标签范围的笔记不再读取或迁移正文，原有卡片编号、评分、排程与历史继续保留；重新纳入后再按当前正文安全核对。文件时间或大小变化、Obsidian 索引正文哈希变化都会触发读取，避免同步工具保留时间戳时漏扫。

习题页文件名模板新增组合时间格式。除原有 `{{title}}`、`{{date}}`、`{{time}}` 外，可组合 `yyyy`、`MM`、`dd`、`HH`、`mm`、`ss`，例如 `{{yyyy-HHmm-ss}}` 或 `{{yyyy-MM-dd}}-{{HHmmss}}`。非法变量和不可移植的文件名字符仍会被拒绝。
