# 快捷制卡与独立识别范围验证

日期：2026-09-05。本功能作为 0.4.4 发布。

## 使用方式

笔记复习底部新增三个按钮：

| 按钮 | 结果 |
| --- | --- |
| 制卡 | 在当前位置之后插入独立的空白 `> [!review]- 复习` 块 |
| 问答 | 在当前复习块插入 `> 问:: ` 与下一行 `> 答:: `；不在块内时自动加复习块 |
| 填空 | 将选中文字包成 `{{c1::选中文字}}`；已有填空编号时递增，周围文字保留 |

原文通过 Obsidian 编辑器修改，可原生撤销。阅读模式下会切换编辑模式；选区无法唯一对应原文时，提示切换编辑模式重新选择。不会在属性区、代码围栏、其他类型 Callout 或复习块标题里直接改写。

完整内容保存后只核对并更新当前笔记，不扫描全库。未完成问答不覆盖旧卡片。修改内容和评分前仍读取当前来源及最新进度；原稳定标识与排程按既有规则保留。连续制卡通过每个路径的版本号防止旧保存回调覆盖新操作。

## 识别范围

设置中“笔记识别”和“卡片识别”分开，每个复习组保存自己的条件。笔记识别整篇文章；卡片识别先筛选文章，再解析其中 `[!review]` 的问答和填空。

| 条件 | 含义 |
| --- | --- |
| 是 | 精确匹配文件所在文件夹或完整标签 |
| 否 | 不满足上述精确匹配 |
| 包含 | 匹配指定文件夹/标签以及子级 |
| 排除 | 排除指定文件夹/标签以及子级 |

例如“全部满足：文件夹包含学习，标签排除草稿”。条件支持全部满足（且）、任意满足（或）；并非任意文字片段搜索。根目录填 `/`；空条件不纳入任何文章；仅否定条件表示在全库中排除对应范围。

旧标签配置继续作为默认范围。切换页面保留草稿，保存规则不重写复习记录；点击主页“整理数据”更新清单。范围外的历史进度保留。批量标签完整改名会同步更新显式标签条件，不改变条件的肯定/否定关系。

## 需要处理

管理页显示具体原因、处理办法和原文跳转；能识别行号时直接定位该行。包括未完成问答、无效填空、代码围栏未关闭、标识重复、卡片离开复习块、旧格式迁移和同步评分冲突。内容变更可展开当前内容核对，再选择保留进度或重新学习。每批显示 50 个问题，可继续展开，修正后可重新检查。

主页顺序为“整理数据 → 开始 → 统计 → 设置”，整理保留阶段和百分比显示。

## 验证

- `npm run check`：28 个测试文件、176 项测试通过，TypeScript 检查及生产构建通过。
- 独立测试 Vault：1,000 篇合成材料，Obsidian 1.13.7；未使用正式笔记进行编辑测试。
- 实际点击三个制卡按钮：空容器、问答模板、选文填空均有效；阅读模式转编辑成功；连续两次局部更新只保存当前来源，整库扫描为 0，原笔记与原卡片排程保持一致。
- 实际设置页保存：笔记与卡片使用不同文件夹范围时，笔记可以纳入而卡片不纳入；保存不扫描、不改变复习记录与历史。
- 修复实际发现的保存卡死：Obsidian 按钮对象本身具有 `then` 方法，原先 `finally(() => button.setDisabled(false))` 隐式返回按钮，造成 Promise 无限处理。两处保存流程明确返回 `void`，补充模拟真实 thenable 按钮的成功/失败回归测试，并在实际设置窗口重新保存验证通过。
- 桌面与 390 像素窄屏检查，制卡触控按钮高度 44 像素。识别页同时使用 Obsidian 手机样式验证布局；没有实体手机或真实软键盘验收。
- 实际未完成问答显示“问答尚未写完整”和处理办法，点击“查看第 29 行”打开正确来源，编辑器定位到第 29 行。
- 本机安装前备份插件及全部 963 个复习数据文件；安装后逐文件散列一致，设置文件未改动。三项插件文件与已测试构建、分发包一致；正式 Vault 的插件运行时尚未重新加载。

安装仍需保留现有 `data.json` 与复习数据目录；升级只覆盖插件程序文件。
