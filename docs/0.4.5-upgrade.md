# 渐进式复习 0.4.5 测试版：正文制卡、稳定编号与流畅度改进

本版允许在卡片识别范围内直接从正文制卡。内置标准 `START/END`、简写 `Q:/A:` 和独立 `{{cN::答案}}` 挖空三种格式，不需要配置正则；原有 `[!review]`、中文 `问::` / `答::`、`^rv-...` 标识和 Anki ID 继续有效。

正文卡首次整理时会获得插件专属隐藏 ID。文件改名、移动、重复整理和缓存重建继续使用同一题目身份、排程与历史；新增挖空不会重新排列已有 `cN`。编号缺失、重复或归属不明时会进入“需要处理”，不会按相似内容猜测绑定。

整理数据新增按知识库隔离的本机解析缓存，只保存全文 SHA-256、解析版本、识别设置和解析结果。文本、规则或版本变化时重新解析；缓存损坏或不可用时正常重建。开始复习不扫描整个知识库，显示与评分当前条目时仍读取当前来源和最新正式进度。

挖空题以横线隐藏答案，揭示后在原句位置显示文字；相同 `cN` 同时揭示，`Extra` 只在答后显示。主页只列出尚未解决的问题，已按确定规则合并的同步冲突保留在诊断信息中。

## 升级

1. 下载并解压 `review-center-0.4.5.zip`。
2. 用其中 `review-center/` 内的 `main.js`、`manifest.json`、`styles.css` 覆盖 Vault 的 `.obsidian/plugins/review-center/` 同名文件。
3. 保留原有 `data.json` 和知识库中的复习数据目录。
4. 重新加载 Obsidian，确认插件版本为 0.4.5。
5. 在主页点击一次“整理数据”，让既有正文题获得稳定标识并建立本机解析缓存。

升级不会清空历史或重置已有到期时间。电脑和手机使用同一套正文识别与稳定编号规则；IndexedDB 缓存属于各设备本机的可重建加速层，不参与同步，也不代替评分前的来源与进度核验。

实体手机尚未验收；手机结论限于 Obsidian 的共享代码路径和 390 × 844 窄屏验证。
