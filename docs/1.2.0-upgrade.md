# 1.2.0 使用与升级说明

最低要求 Obsidian 1.13.0。内部 ID 保持 `review-center`。[下载完整安装包](https://github.com/812344707/obsidian-review-center/releases/download/1.2.0/review-center-1.2.0.zip)。

## 本版变化

“整理数据”现在先用 Obsidian 元数据核对全库标签、路径和来源标识，再只读取新增、重新纳入、正文发生变化或解析规则变化的知识点笔记。首次从旧版升级后，已纳入笔记会补充扫描指纹；从下一次整理开始，未变化正文可以跨重启跳过。

移出标签范围的材料不读取或迁移正文，但原有卡片编号、评分、排程与历史继续保留。重新纳入时，插件会重新读取并按当前规则核对。

习题页文件名模板继续支持 `{{title}}`、`{{date}}`、`{{time}}`，并增加 `yyyy`、`MM`、`dd`、`HH`、`mm`、`ss` 的组合格式。例如 `{{yyyy-MM-dd}}-{{HHmmss}}` 会生成本地日期与时间。

## 升级步骤

1. 等待同步完成，备份插件目录和复习数据，暂时关闭插件。
2. 将安装包 `review-center/` 内的 6 个程序与许可文件复制到现有 `.obsidian/plugins/review-center/` 内，覆盖同名文件。
3. 保留已有 `data.json` 和复习数据目录，不要删除整个旧插件目录。
4. 重新启用插件，确认版本为 1.2.0。
5. 点击一次“整理数据”，让当前纳入的旧记录补充扫描指纹。第一次可能接近旧版耗时，之后才体现增量读取。

升级不会重置已有笔记、卡片、评分、排程或历史。功能与语法见[使用手册](user-guide.md)，已测范围见[验证记录](1.2.0-validation.md)。
