# 1.0.0 使用与升级说明

状态：本地发布候选，尚未公开发行。最低 Obsidian 版本为 1.13.0，内部 ID 保持 `review-center`。

本版以现有两条流程作为首个正式版范围：笔记在原文中阅读、整理，按天安排回顾；知识点以问答和挖空卡片复习。自定义标签管理范围，分别设置参数，沿用 FSRS、稳定编号、备份和历史。

## 相对 0.4.6 的整理与修正

- 修复首次整理写入编号后，索引短暂更新导致知识点被漏掉的问题；同次整理使用写入前已核验的标签范围。
- 异常笔记标识会在整理和文件访问前被拦截。损坏或未同步完整的复习记录不再被忽略后当作新内容处理。
- 恢复备份前校验来源、卡片、日期、排程、历史和重复 ID，校验失败时保留本地数据。
- 本机首页和会话改用 Obsidian 的知识库隔离接口。同名知识库互不混用；本机存储失败不会让已经保存的评分显示成失败。
- 关闭插件会取消尚未执行的界面定位回调，避免评分栏被延迟回调重新创建。
- 设置页接入 Obsidian 1.13 的原生设置定义与搜索，保留横向分类、标签联想、草稿和显式保存。
- 统一入门说明与详细手册，历史版本说明移入更新记录。增加官方检查、自动打包验证与问题反馈模板。

## 升级步骤

1. 备份知识库，暂时关闭插件。
2. 将 `review-center-1.0.0.zip` 内的 6 个文件复制到原插件目录内，覆盖同名程序和许可文件。不要替换或删除整个插件文件夹。
3. 保留原 `data.json` 和知识库中的复习数据目录。
4. 重新启用插件，检查版本号为 1.0.0。
5. 返回主页选择范围，按已有排程开始。新增或修改材料后再点击“整理数据”。

升级不清空排程、评分历史或自定义参数。0.4.6 及更早版本按知识库名称保存的临时队列和首页位置无法可靠确认所属知识库，因此本次不自动迁入；首次升级后重新选择范围开始，使用已有复习进度，之后的续接按知识库独立保存。原有撤销历史不删除，但旧版尚未结束会话中的“撤销最近一次”不跨此次临时队列切换迁移。

从 0.4.5 或更早版本升级时，还包含 [0.4.6 的标签与按天回顾调整](0.4.6-upgrade.md)：原组合分组继续保留，笔记旧默认最长间隔一次性改为 90 天，已有远期排程不批量提前。更早的旧章节转换继续沿用备份后迁移流程。

## 数据异常时

出现“记录尚未完整读取”时，先等同步完成后重试。如果持续失败，根据提示定位到具体进度文件并核对备份。不要删除记录或改写 `review_id` 来绕过提示。正常原文、记录和历史会继续保留。

本版未引入账号、付费服务、自动制卡、手机后台通知或跨笔记移动卡片进度的功能。

验收范围与发行前待办见 [验证记录](1.0.0-validation.md) 和 [正式版准备记录](release-readiness-1.0.0.md)。
