# 1.5.0 验证记录

> 状态：自动化、可复现打包与 Obsidian 设置页实机验收已通过；生产旧目录的最终清理由用户在确认风险后另行执行。日期：2026-09-20。

## 自动化范围

- 提供商预设、旧设置归一化和自定义端点保留。
- OpenAI Responses、OpenAI 兼容 Chat Completions、Anthropic Messages、Gemini generateContent 请求构造与响应解析。
- Bearer、Anthropic `x-api-key`、Gemini `x-goog-api-key` 鉴权边界；非本机 HTTP 拒绝。
- 数据目录复制、逐文件核对、中断续接、同步竞争检测、系统废纸篓与知识库 `.trash` 回退。
- 遗留目录清理对当前活动目录、父目录、子目录和不存在路径的保护。

## 人工验收边界

- 不使用真实第三方 API 密钥，不把生产笔记发送给外部服务；协议级验证使用模拟响应。
- 发布后应回下载公开附件并校验 ZIP、SHA256SUMS、ZIP 内六个文件和生产部署文件一致。
