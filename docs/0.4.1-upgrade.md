# 0.4.1 测试版：实用复习统计

本次在 0.4.0 的独立统计页中增加四项实用统计，保留手绘主页与所有复习功能。

| 统计 | 用来回答的问题 |
| --- | --- |
| 今日概览 | 今天新学、复习了多少？有记录的练习用了多久？ |
| 到期安排与积压 | 还有多少积压？未来一周是否过于集中？ |
| 近期复习趋势 | 最近的学习量和时间投入是否合适？ |
| 记忆保留率 | 间隔一段时间后，实际能回忆起多少内容？ |

未增加卡片难度、稳定期、预测回忆概率、间隔直方图、逐小时成功率、独立按钮分布及新增库存图。它们更适合排查具体排程问题；本版优先让统计支持每日安排和月度回顾。现有热力图继续显示练习习惯，不新增重复的活动日历。

## 使用与口径

从主页“统计”进入，默认查看当前笔记／卡片模式和所选范围；可选择全部组、单组或标签分支。切换后只影响统计，返回恢复主页位置。时间选项保存在本机；统计数字随复习、撤销和刷新更新。

- **今日新学／复习**：同一内容当天按首次有效评分分类；重复练习仅增加评分次数和记录用时。旧数据无法分类时单独说明。
- **记录用时**：合计已评分的前台复习记录，每次最多 5 分钟；缺少用时不当作测得的 0 秒。暂停、退出和后台时间不计。跨午夜练习归入评分日。
- **未来 7／30 天**：从明天起按每天展示当前已排定的下次复习。每项仅出现一次；学习、重学和正常复习均计入。逾期和今日剩余另外显示，数字不受每日上限截断。暂停、待确认、未学习和范围外内容排除；搁置项归入恢复日。此图会随评分变化，不是未来实际练习次数的预测。
- **近期 7／30 天**：默认按天堆叠新学／复习数量；可切换用时。缺少用时的日期显示“—”或部分记录说明；不伪造旧时长。
- **记忆保留率**：距上次练习至少 24 小时、当天首次有效评分才参与；重来为忘记，困难／良好／简单为记得。显示近 7 天、30 天、365 天的记得／忘记数量和比例。无样本为“—”，近 30 天不足 30 次时提示先观察。30 次仅作为小样本提示门槛，不代表达到统计显著性。笔记模式是对整篇笔记的自评，不能等同于逐知识点的客观测试。
- **历史范围**：先去重并处理全部撤销，再按评分时的模式／组／标签筛选；旧记录缺少归属时按现有标签判断。全部范围保留已删除笔记的历史。重复练习不会因同一天切换标签范围再次成为首次评分。

参考资料：[Anki 官方统计说明](https://docs.ankiweb.net/stats.html#true-retention-table) 以及用户提供的 Anki 统计 PDF。本版使用明确的 24 小时间隔条件；不声称与不同 Anki 版本的统计逐项数值一致。

## 升级与数据保护

1. 解压 `review-center-0.4.1.zip`。
2. 将 `review-center/` 中的 `main.js`、`styles.css`、`manifest.json` 覆盖到知识库的 `.obsidian/plugins/review-center/`。保留原 `data.json` 和复习数据目录。首次安装应复制整个插件目录，保留随包的许可证文件。
3. 重新加载插件，在主页打开统计即可。

本次保持设置／备份格式版本 4，不需要迁移笔记、重制卡片或重新排程。为今后的保留率统计，新评分事件增加可选的 `beforeSchedule`（评分前排程）；旧日志原样保留，不回写或补造缺失信息。旧数据通过相邻修订快照还原评分前排程，无法准确还原时排除并说明。新字段随完整及范围备份保留，旧版本备份继续可读。

这是本地测试版，尚未发布 GitHub，也不会自动安装到你的正式知识库。明暗主题、手机宽度与数据保护的实际测试结果见同目录验证记录。
