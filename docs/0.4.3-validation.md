实际窗口可观察到多个递增的中间百分比。390 px 窄屏下主页按钮可见、操作区无水平溢出，按钮高度至少 44 px。该检查使用桌面窄窗口，尚未在实体手机上验收。

另验证来源改名后可以继续复习；显示答案后修改原文，再点击旧评分按钮会拒绝评分并显示内容已修改。该过程没有新增评分历史，原排程保持不变，也没有触发整库扫描。
