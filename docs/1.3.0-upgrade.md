# 1.3.0 使用与升级说明

1. 关闭 Obsidian 中的“渐进式复习”，并备份知识库。
2. 下载 `review-center-1.3.0.zip`，把其中 `review-center` 文件夹内的 6 个文件覆盖到原插件目录。
3. 保留原插件目录中的 `data.json`，并保留知识库内已有的复习数据目录；不要用安装包文件夹整体替换原目录。
4. 重新打开 Obsidian 并启用插件。需要统一标记以后新建的习题页时，进入设置 → 渐进式复习 → 习题页，添加“习题页标签”并保存。

自定义标签会与来源笔记标签合并并去重，只影响保存设置后新建的习题页。留空继续只复制来源标签；升级不会修改已有习题页、复习数据、稳定标识或排程。

最低要求 Obsidian 1.13.0。若跨设备同步插件设置，请先等待同步完成，再在另一设备创建习题页。
