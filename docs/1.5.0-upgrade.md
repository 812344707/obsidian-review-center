# 1.5.0 使用与升级说明

1. 退出 Obsidian，或先停用“渐进式复习”。
2. 下载 `review-center-1.5.0.zip`，把其中 `review-center` 文件夹内的 6 个文件覆盖到原插件目录。
3. 重新打开 Obsidian 并启用插件。升级包不含 `data.json`、`.review-center/settings.json`、API 密钥、笔记或复习数据，现有设置继续保留。

## 自动出题接口

“设置 → 渐进式复习 → 自动出题”新增常见提供商预设。选择预设只会填写协议和请求地址，不会替你选择模型、创建账号或写入密钥；模型 ID 与地区端点应以服务商控制台为准。API 密钥值仍由 Obsidian SecretStorage 保存。

旧设置自动兼容：原 OpenAI Responses 和 Chat Completions 配置不会被重置；保存后会附加提供商标识。自定义地址仍可继续使用。

## 数据目录迁移

新迁移在完成复制、逐文件核对、设置保存及新目录重新读取后，才处理旧目录。默认先尝试系统废纸篓，系统不支持时使用知识库 `.trash`。若 Obsidian Sync 或其他程序在最后核对后写入旧目录，插件会保留旧目录并提示，不以清理成功换取数据风险。

旧版本已经留下的目录不会被静默删除。请在“数据与备份 → 清理迁移遗留目录”明确填写旧路径并确认。插件会拒绝当前活动目录及其父子目录，并在操作前备份当前活动数据。启用同步时，删除可能同步到其他设备。
