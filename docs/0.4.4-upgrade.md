# 渐进式复习 0.4.4 测试版：快捷制卡与独立识别

本版在笔记复习底栏加入“制卡”“问答”“填空”。“制卡”插入空白 `[!review]` 块；“问答”插入 `问::` 与 `答::`；选中文字后点“填空”，原文字会保留在 `{{c1::原文字}}` 中。完整内容保存后只更新当前笔记的卡片清单，不重新扫描整个知识库。

笔记识别和卡片识别现在分别设置。每个复习组可使用文件夹或标签条件，并选择“是／否／包含／排除”，多条条件按“全部满足”或“任意满足”组合。旧版标签范围会继续生效；设置新公式并保存后，在主页点击“整理数据”更新清单。移出范围的内容保留排程与历史。

主页顺序调整为“整理数据 → 开始 → 统计 → 设置”。“需要处理”会显示问题原因、建议处理办法，并在可以确定行号时直接打开原文对应行。内容变化先核对，再选择保留进度或重新学习。

本版还修复了一个设置保存卡死问题：保存按钮对象被 Promise 继续处理时会造成界面占满 CPU。现在保存成功和失败都会正常恢复按钮，不会触发循环。

## 升级

1. 下载并解压 `review-center-0.4.4.zip`。
2. 用其中 `review-center/` 内的 `main.js`、`manifest.json`、`styles.css` 覆盖 Vault 的 `.obsidian/plugins/review-center/` 同名文件。
3. 保留原有 `data.json` 和知识库中的复习数据目录。
4. 重新加载 Obsidian，打开“渐进式复习”。
5. 检查“笔记识别”和“卡片识别”的范围；需要采用新公式时保存后点击一次“整理数据”。

升级不会清空复习历史，也不会重置已有到期时间。另一设备的评分和原文修改仍须先通过原有同步方式到达本机；当前条目在显示、评分或确认修改前继续读取本机最新来源与进度。
