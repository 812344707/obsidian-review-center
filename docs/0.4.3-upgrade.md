# 渐进式复习 0.4.3 测试版：整理材料与快速开始

本版把“更新材料”和“开始复习”明确分开。首次使用，或新增笔记、改标签、完成跨设备同步后，在主页点击“整理材料”；平时直接点击“开始”。整理过程中会显示阶段、进度条和百分比，保存完成才显示 100%。

开始和继续不会重新扫描整个知识库。插件只读取当前要显示的来源，并核对本机已收到的最新复习进度。来源改名、删除、离线修改、标签移出范围，以及手机同步来的评分，都会在当前条目实际使用前处理；内容或进度变化时，旧界面上的评分不会写入。

电脑和手机采用相同流程，手机无需等待电脑先整理。另一台设备的更改仍须先通过原有同步工具到达本机，插件不会绕过同步服务读取远端状态。

插件显示名称由“复习中心”改为“渐进式复习”，英文名为 “Progressive Review”。内部 ID 仍为 `review-center`，GitHub 仓库和默认数据目录保持不变，因此升级会继续识别原插件设置、排程和历史。

## 升级

1. 下载并解压 `review-center-0.4.3.zip`。
2. 用其中 `review-center/` 内的 `main.js`、`manifest.json`、`styles.css` 覆盖 Vault 的 `.obsidian/plugins/review-center/` 同名文件。
3. 保留原有 `data.json` 和知识库中的复习数据目录。
4. 重新加载 Obsidian，打开“渐进式复习”。

升级不清空复习历史，也不会重置已有到期时间。若主页提示材料有变化，可点击一次“整理材料”更新清单。
