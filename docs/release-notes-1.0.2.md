# 1.0.2 · 填空题长答案排版修复

修复填空题显示长答案时整块居中、换行错乱和英文长串撑破卡片的问题。单段答案现在随正文自然换行；包含换行的答案在独立答案区保留段落、列表、粗体、代码和链接格式。

同时修复答案含行内代码时填空标记未替换的问题，限制长提示宽度，并恢复补充材料的普通高亮样式。

[下载完整安装包](https://github.com/812344707/obsidian-review-center/releases/download/1.0.2/review-center-1.0.2.zip)。最低要求 Obsidian 1.13.0；升级保留原有 `data.json` 和复习数据目录，无需重新制卡。

261 项自动测试、Obsidian 1.13.7 的 60 个原生渲染场景通过。窄屏为桌面模拟，真实移动设备和并发同步仍待验证。[升级说明](1.0.2-upgrade.md) · [验证记录](1.0.2-validation.md)。
