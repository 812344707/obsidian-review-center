# 渐进式复习 1.0.0 · 首个正式版

发行说明草稿，尚未发布。

在原文中回顾和整理笔记，用问答与挖空复习知识点，以自定义标签组织范围。

- **整理笔记**：原生目录定位当前文件，方便移动和处理；回顾间隔按天自动安排。
- **复习知识点**：正文与复习提示块制卡，独立参数和学习步骤，支持揭示、评分和撤销。
- **保持进度**：稳定编号、内容变更确认、备份恢复和同步核对；异常记录先拦截，避免重置或覆盖现有进度。
- **更清楚的设置**：笔记和知识点各一行标签配置，常用参数直接显示，高级设置折叠。

相对 0.4.6，修复首次整理时索引更新造成知识点漏识别，补齐数据校验、本机会话隔离、关闭清理、原生设置搜索及发行检查。升级时逐文件覆盖程序，保留 `data.json` 和复习数据目录；首次升级后重新选择范围开始，沿用已有排程。

最低要求 Obsidian 1.13.0。正式发布前须将 [验证记录](1.0.0-validation.md) 和 [准备记录](release-readiness-1.0.0.md) 中的验收状态核对完成。

本地已通过 238 项测试、生产构建、Obsidian 1.13.7 新安装／升级验收和安装包校验。手机真机与真实同步仍待验收。
