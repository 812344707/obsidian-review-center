# 0.3.0 升级说明

本版为本地安装测试版，最低需要 Obsidian 1.13.0。

## 安装

1. 解压 `review-center-0.3.0.zip`。
2. 将 `review-center` 文件夹放入知识库的 `.obsidian/plugins/`。已有插件时，只覆盖 `main.js`、`manifest.json`、`styles.css`，保留 `data.json`。
3. 重新加载插件。打开设置检查现有复习组；从 0.2.0 升级会保留标签集、顺序和参数。

## 旧复习章节怎样变化

过去以旧设置指定的标题（默认为 `## 复习`）制作卡片；现在统一使用指定类型的提示块。默认示例：

```markdown
> [!review]- 复习
> 问:: 这一节的核心观点是什么？
> 答:: 这里填写答案。
```

每篇可有多个块，位置和标题可以自由安排。`-`、`+` 或不写折叠符号都能识别。多个独立块之间留一行不带引用符号的空行。块内仍使用原来的问答、挖空语法。

第一次扫描会自动转换已管理的旧复习章节，包括暂时退出复习标签范围的来源笔记。以后纳入的旧笔记也会先转换。旧标题配置只作为迁移输入，不再独立制卡。

每次转换都先保存原始笔记和复习数据，再核对转换前后的卡片数量、内容和标识。纯格式转换保持排程、到期时间和历史，不产生新卡或内容修改提示。已转换的笔记不会再次转换，中断后重新扫描可继续。

默认数据目录中的备份位置：

- `复习中心数据/exports/pre-callout-migration-*.json`：转换前的设置、排程和历史，支持通过插件“恢复 JSON 备份”读取。
- `复习中心数据/migrations/callouts/*.json`：逐篇保存原文件路径、完整 Markdown 和对应排程，供核对原文。该文件属于原文备份，不是“恢复 JSON 备份”的导入格式。

重复旧标题、重复标识、已有嵌套结构无法安全转换或内容无法对应时，插件保留该篇原文和进度，在首页列出待处理笔记。根据提示整理原文后重新扫描。请保留 `review_id` 和带 `>` 引用前缀的 `^rv-...` 行。

如果已有卡片标识仍留在笔记里，但移出了可识别复习块，插件会报告问题并保留排程，避免误删进度。真正删除卡片及其标识后，才按原有规则移除对应排程。

## 设置与批量纳入

选择“笔记复习／卡片复习”后，从下拉框选择当前组。常用参数直接显示，学习步长等放在“更多参数”。切换组保留草稿，点击“保存”才生效。“管理复习组…”集中提供新增、复制、排序和删除。

标签输入可选择已有标签和父标签，也可输入合法新标签。选择父标签自动包含其子标签，例如 `#中医` 包含 `#中医/伤寒`，不包含 `#中医基础`。

“批量添加标签”可从设置或命令面板进入，按文件夹或标签集筛选。预览会列出每篇将新增的标签，可取消个别文件。执行前再次检查文件，发生变化或属性无法解析时跳过并逐篇报告。重复执行不会重复补充已有标签。正文保留，属性排版可能规范化；纳入复习的笔记按正常扫描规则补充稳定标识。

## 更换数据目录

输入知识库内相对路径，或选择已有空文件夹。输入过程不切换，点击“应用并迁移”后才执行：暂停相关写入 → 等待在途操作 → 完整备份 → 复制和逐项核对 → 保存新路径 → 重新读取。

新旧目录不能互相包含，目标非空时不会覆盖。成功后旧目录保留；失败仍使用旧路径。若在复制阶段中断，再次填写相同目标并应用即可继续；若新路径已经保存，重启后从已核对的新目录读取。不要手动改动未完成迁移的目标文件，外部修改会使插件停止覆盖并提示选择其他空目录。

新备份格式为 v3，兼容读取 v1／v2。恢复始终使用当前数据目录，并先另存恢复前备份。自动章节转换不可通过简单覆盖旧版插件来逆转；如需回退，应同时使用升级前笔记和数据备份，避免旧版无法识别新的 Callout。

## 验证范围

已做自动化测试和 Obsidian 临时知识库检查，包含 390×844 手机模拟及明暗主题。尚未在 iOS／Android 真机和两台设备并发同步环境中验证，详见 `0.3.0-validation.md`。
