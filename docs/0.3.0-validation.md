## 实测修正

- Obsidian 默认按钮规则覆盖彩色底色：提高评分按钮样式优先级，同时设置文字颜色。
- 手机设置将嵌套标签按钮撑满整行：限制添加／移除按钮宽度，恢复输入空间，消除横向溢出。
- 设置切换保留尚未按回车的标签草稿。
- 原文评分栏原先位于设置窗口之上：调整到弹窗层之下，避免遮挡设置操作。
- 属性格式错误提供可读的中文提示。
