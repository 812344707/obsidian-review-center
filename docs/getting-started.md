# 第一次使用

## 安装

最低要求 Obsidian 1.13.0。首次安装，把 ZIP 内的 `review-center/` 放到知识库的插件目录，通常为 `.obsidian/plugins/`，再启用“渐进式复习”。已有版本按 [升级步骤](1.1.0-upgrade.md) 逐文件覆盖，保留 `data.json` 和复习数据目录。

下载 [1.1.0 正式版完整安装包](https://github.com/812344707/obsidian-review-center/releases/download/1.1.0/review-center-1.1.0.zip)，历次版本见 [GitHub Releases](https://github.com/812344707/obsidian-review-center/releases)。

## 建立一篇示例

新建 Markdown 笔记，粘贴以下内容：

```markdown
---
tags: [review]
---
# 一条值得回顾的想法

笔记复习时，我会阅读、补充、整理这篇原文。

Q: 我希望从这篇笔记记住什么？
A: 用一句自己的话回答。

复习时先尝试 {{c1::主动回忆}}，再看答案。
```

## 开始复习

1. 点击侧栏的脑形图标，进入“渐进式复习”。
2. 点击“整理数据”。默认 `#review` 同时用于整篇笔记和文章中的知识点。
3. 选择“笔记”及对应标签，点击“开始”，阅读原文、整理文件，再给出评分。左侧原生文件列表会自动定位当前笔记；侧栏收起时可自行展开。
4. 返回主页选择“卡片”，开始知识点复习：先回忆，再揭示答案，最后评分。

笔记评分按天安排，最早次日再次出现；知识点保留分钟级学习步骤。新建笔记组默认每天新笔记 1 篇、到期回顾 10 篇、最长间隔 90 天，可在对应标签齿轮 → 选项中修改。

## 换成自己的标签

在“设置 → 渐进式复习 → 复习标签”中，分别设置笔记和知识点标签。例如 `#阅读` 自动包含 `#阅读/医学`。保存后给原文添加标签，再点击“整理数据”。只修改设置不会自动给文章打标签。

## 看不到内容时

- 第一次使用或新增材料后，先点击“整理数据”。
- 确认标签配置与笔记标签一致。知识点还需要有效的问答或挖空格式。
- 今日额度用尽或内容尚未到期时，正常队列为空；可到对应标签选项核对额度。
- “需要处理”或错误提示会说明具体原因。遇到索引／同步未完成时，等完成后重试；异常编号或记录请依据备份核对，不要删除进度文件来消除提示。

更多格式、参数、统计与数据说明见 [使用手册](user-guide.md)。
