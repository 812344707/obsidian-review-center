# 1.1.0 · 独立习题页

笔记复习底栏新增“习题页”。每次点击都会按设置的文件夹和文件名模板创建独立习题笔记，在新标签页进入编辑模式，并在原文创建时的光标位置插入指向新页的内部链接。

习题页包含原文链接、原文当时的全部标签和空白编辑区，沿用现有“制卡、问答、填空”及扫描规则。它使用独立的笔记和卡片标识，不继承原文的排程与历史；重新打开、移动或重命名后仍能识别。

设置新增“习题页”分类。文件名模板支持 `{{title}}`、`{{date}}` 和 `{{time}}`，自动补 `.md`，同名文件依次增加 `-2`、`-3`。路径校验会拒绝绝对路径、上级目录、隐藏目录和插件数据目录。

[下载完整安装包](https://github.com/812344707/obsidian-review-center/releases/download/1.1.0/review-center-1.1.0.zip)。最低要求 Obsidian 1.13.0；升级保留现有 `data.json`、笔记、卡片编号、评分与排程。

自动检查和 macOS 隔离 Vault 原生界面验证通过。真实移动设备与跨设备并发同步仍待验证。[升级说明](1.1.0-upgrade.md) · [验证记录](1.1.0-validation.md)。
