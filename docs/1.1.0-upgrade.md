# 1.1.0 使用与升级说明

最低要求 Obsidian 1.13.0。内部 ID 保持 `review-center`。[下载完整安装包](https://github.com/812344707/obsidian-review-center/releases/download/1.1.0/review-center-1.1.0.zip)。

## 本版变化

笔记复习底栏新增“习题页”。创建成功后，插件在新标签页打开独立习题笔记，并在原文创建时的光标位置插入内部链接。新页复制原文链接和全部标签，底部继续提供“制卡、问答、填空”。

设置 → 习题页可修改保存文件夹和文件名模板。默认文件夹为 `习题`，默认模板为 `{{title}}-习题-{{date}}-{{time}}`。日期格式为 `YYYY-MM-DD`，时间格式为 `HHmmss`。

习题页拥有独立的笔记、卡片编号、排程与历史。复制的标签仍按已有标签和文件夹规则决定是否进入笔记或知识点复习。

## 升级步骤

1. 等待同步完成，备份插件目录和复习数据，暂时关闭插件。
2. 将安装包 `review-center/` 内的 6 个程序与许可文件复制到现有 `.obsidian/plugins/review-center/` 内，覆盖同名文件。
3. 保留已有 `data.json` 和复习数据目录，不要删除整个旧插件目录。
4. 重新启用插件，确认版本为 1.1.0。
5. 打开设置 → 习题页，按需调整文件夹和文件名模板；旧设置缺少这些字段时自动使用默认值。

升级不会修改已有笔记、卡片、评分、排程或历史。新建习题页后，如需让其中的新卡片进入复习，按原流程点击一次“整理数据”。

功能与语法见 [使用手册](user-guide.md)，已测范围见 [验证记录](1.1.0-validation.md)。
