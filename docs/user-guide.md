# 使用手册

知识点以问答和挖空卡片形式复习，界面中的“卡片”指知识点复习；“笔记”指整篇原文的阅读和整理。

[首次使用](getting-started.md) · [升级说明](1.0.0-upgrade.md) · [返回项目首页](../README.md)

## 设置复习范围

1. 打开“设置 → 渐进式复习 → 复习标签”，在“笔记复习标签”和“知识点复习标签”中选择已有标签或输入新标签，点击“保存”。两个输入可以填相同或不同的标签；默认均为 `#review`。
2. 在需要复习的笔记属性或正文中打上相应标签。父标签自动包含子标签，无需逐级配置。
3. 在主页点击“整理数据”，选择标签或其子标签，再点击“开始”；同一范围有未完成会话时，再点“开始”即可接着复习。

笔记标签用于整篇阅读和整理；知识点标签用于识别对应笔记中的问答和挖空，两类复习进度和参数独立。添加标签到设置不会自动修改文章，可用下方“批量添加标签”预览并补充原文标签。

例如，笔记包含：

```yaml
tags:
  - 复习/笔记/伤寒
  - 复习/卡片/伤寒
```

笔记组可选择 `#复习/笔记`，卡片组可选择 `#复习/卡片`。卡片继承来源笔记的全部标签；同一篇笔记可以只进入笔记复习、只进入卡片复习，或同时进入两者。

每个自定义标签形成一组，父标签包含所有下级标签，匹配不区分大小写。`#中医` 匹配 `#中医/伤寒`，不会匹配 `#中医基础`。同一内容命中多个组时，更具体的标签优先；同层级沿用原有顺序，新标签追加在后，每个复习项只保留一份排程。

从设置中移除标签会停止通过它纳入复习，保留原文中的实际标签、历史和排程；重新匹配后继续使用。笔记改名、换文件夹不会改变其身份和复习进度。

输入标签时可从联想列表选择，桌面支持方向键和回车，手机可直接点选；也可输入新标签后点“添加”或按回车。保存也会接收尚未点击“添加”的有效输入。属性标签、正文标签及其父级都会出现在建议中。切换设置分类保留草稿，“还原草稿”恢复已保存内容。

旧的组合条件不会被猜测转换：只在存在这类配置时显示折叠的“原有分组”。可以选择一个标签并点击“改用标签”，保存后以该标签及子标签代替原范围，保留组 ID、参数和复习进度。组内原来多个标签共享的参数与限额也不会被自动拆分。

### 批量添加标签

从设置页或命令面板打开“渐进式复习：批量添加标签”。按文件夹筛选时默认包含子文件夹，可关闭；按标签集筛选时可选“满足任意一个”或“同时满足全部”，两者均包含子标签。

填写额外标签后点击“预览匹配文章”，检查文件清单和每篇将新增的标签，取消不需要的文件，再执行。仅补充笔记属性中的 `tags`，已有属性标签或正文标签不会重复添加，正文保留；属性的排版可能重新格式化。插件数据目录自动排除。预览后发生变化、属性无法解析或写入失败的文件会跳过并报告，重新预览后可重试。完成后自动刷新复习数量；新纳入的文章会正常补充 `review_id` 和卡片稳定标识。

## 复习参数

进入复习页面或打开复习中的笔记时，自动启用 Obsidian 文件列表的“自动显示当前文件”（Auto-reveal active file）。切换笔记后，原生目录自动定位到对应文件，便于直接移动和整理；这个原生开关开启后会保留。文件列表其他设置和侧栏展开状态保持原样。

在主页点击复习组或标签行的齿轮，选择“选项”。笔记用于阅读和整理，“常用设置”显示**每日新笔记、每日回顾、最长间隔（天）**；卡片显示**每日新内容、每日复习、目标记忆率**。编辑的是当前使用的参数预设，多个组共用同一个预设时，修改会一并应用到这些组。

“高级设置”统一管理预设选择、复制、继承、当前组／分支单独设置、仅限今日额度，以及学习步长、排列顺序和 FSRS 优化。单独设置留空即恢复继承；仅限今日的额度在次日失效。已有单独设置时，常用区会提示当前行的生效数值，并提供直达入口。切换组和展开／折叠保留草稿，点击“保存”后统一应用；“还原草稿”撤回尚未保存的修改。

| 参数 | 新建笔记组 | 新建卡片组 |
| --- | --- | --- |
| 每日新内容 | 1 篇 | 10 张 |
| 每日到期复习 | 10 篇 | 100 张 |
| 目标记忆率 | 85%（高级设置） | 90% |
| 学习步长 | 按天自动安排，关闭短期步骤 | `1m 10m` |
| 重学步长 | 按天自动安排，最早次日 | `10m` |
| 最大间隔 | 90 天 | 36500 天 |

笔记继续使用 FSRS，关闭短期学习／重学；四档评分的间隔始终以天显示，按设备当地日期到期。例如晚上选择 1 天后，次日零点即可回顾。没有手动指定日期功能。默认每天新笔记 1 篇、回顾 10 篇，先控制整理负担；90 天上限便于定期回访，均可自行调整。

升级时保留已有每日额度、记忆率和自定义最长间隔；旧版默认的 36500 天笔记上限一次性调整为 90 天。笔记的分钟学习步骤停止使用，已有当天短期待复习笔记最早次日再出现；不重写历史或清零进度。新的最长间隔默认从下次评分起生效，已有远期排程不会因升级而批量提前。

目标记忆率可设为 70%–99%，更高通常意味着更多复习。卡片步长用空格分隔，`m` 为分钟，`h` 为小时，每步至少 1 分钟且小于一天；留空交给 FSRS 安排。新参数默认从下次评分起生效；明确开启“更改时重新排程”才会预览并调整已有到期日期。

每日限额按设备当地自然日（午夜换日）、复习类型和复习组累计，重新开始或重启不会重置。新内容与到期复习分别计额，同项当天多次练习只占一次对应额度，按当天首次有效评分时的组记账；各组额度独立；子标签可选择是否受顶层组总限额约束。首页显示当前限额内可练习数量，已搁置和尚未到时间的内容不计入。

提供“重来、困难、良好、简单”四档评分与间隔预览。卡片短期练习到时后，尚未关闭的复习会话会自动补入到期内容（最多约 15 秒刷新）；笔记到期日期变化后同样会更新队列，也可在首页点击“开始”。支持撤销最近评分、退出后自动续接、暂停、恢复和重置。

## 制作卡片

文章先要命中知识点复习标签（旧组仍按保存的范围）。正文按“标准块 → 简写问答 → 独立挖空”的顺序识别；属性、注释、代码示例和其他 Callout 不制卡。整篇文章是否进入笔记复习，由笔记复习标签决定。

简写问答适合单段答案，空行结束答案：

```markdown
Q: FSRS 的作用是什么？
A: 根据每次评分估计记忆状态，并安排下一次复习。
```

需要多段答案时使用标准问答。首字段 `Front:` 可以省略：

```markdown
START
Basic
Front: FSRS 的作用是什么？
Back: 根据每次评分估计记忆状态。

- 再安排下一次复习
- 答案可包含 Markdown
END
```

独立正文段落中的挖空可直接识别；相同 `cN` 同时隐藏和揭示，不同编号生成不同卡片：

```markdown
FSRS 使用 {{c1::稳定性::记忆强度}}、{{c2::难度}} 和 {{c3::可提取性}} 描述记忆。
```

卡片可以用独立一行 `Extra:` 附加答后补充。`Extra:` 是字段标记，不会显示在卡片中；点击“显示答案”后，补充内容显示在答案下方，支持 Markdown 文字、链接和图片。标准 Basic/Cloze、正文简写问答、正文独立挖空和 `[!review]` 内的问答/挖空均支持；`Extra:` 可留空或省略。补充里的挖空语法不会生成额外卡片。

```markdown
START
Basic
Front: 这张图说明什么？
Back: 这里填写答案。
Extra:
这里填写解释或来源。

![[附件/示意图.png|500]]
END
```

正文简写问答示例（`Extra:` 和补充内容与答案之间不留空行；空行结束该卡片）：

```markdown
Q: 问题是什么？
A: 这里填写答案。
Extra: 这里填写补充说明。
![[附件/示意图.png|500]]
```

正文独立挖空的补充也须在同一段落内；多段补充推荐使用标准块。Callout 内每行保留 `>`，例如 `> Extra: 补充说明`。问答卡仍须填写答案，补充不能代替答案。已有卡片首次按新规则整理时会显示内容修改，请核对后选择保留或重置进度。需要显示字面 `Extra:` 示例时，请将它放入代码格式。

标准挖空的首字段 `Text:` 可以省略：

```markdown
START
Cloze
Text: FSRS 使用 {{c1::稳定性}} 描述记忆强度。
Extra: 稳定性越高，遗忘速度通常越慢。
END
```

旧笔记继续支持 `[!review]`，不会批量改写：

```markdown
> [!review]- 核心概念
> 问:: FSRS 的作用是什么？
> 答::
> 根据每次评分估计记忆状态，并安排下一次复习。
>
> - 答案可包含多段内容
> - 支持列表、链接、图片和其他 Markdown

正文可继续写在复习块之间。

> [!review]- 挖空
> FSRS 使用 {{c1::稳定性}}、{{c2::难度}} 和 {{c3::可提取性}} 描述记忆。
```

旧问答答案延续到下一张 `问::` 或下一个子标题。旧问答后要写独立挖空时，请另起子标题。正文简写问答中的 `{{cN::...}}` 属于问答内容，不会再生成挖空卡；要同时制作两类题，请将挖空另起独立段落或标准块。

同一个块内可放多张问答或挖空卡片；多个独立 Callout 之间留一行不带 `>` 的空行。其他类型 Callout、代码示例、注释和嵌套块不会单独制卡；普通正文中的标准问答和挖空按前述规则识别。

插件在纳入的笔记属性中维护 `review_id`。旧 Callout 卡继续使用 `^rv-...`；正文卡使用隐藏的 `<!--review-center-id: rv-...-->`。请保留这些标识。每个挖空由稳定 ID 与 `cN` 共同确定；新增编号不会改变已有卡片。内容修改后可选择保留或重置进度；明确删除后退出队列并由历史保留删除记录。编号重复或归属不明时暂停相关处理，不按相似内容猜测绑定。

## 统计与热力图

主页点击“统计”进入独立页面，初始查看所选组／标签范围，可切换为全部复习组和另一种复习模式。统计筛选、时间切换不改变主页选择、复习参数和进度；返回后恢复主页的树形位置。

今日概览与近期趋势按每天首次有效评分区分新学、复习，同项当天反复练习只计一项。用时合计有记录的部分，未记录用时明确标注；未评分的阅读时间不计入，跨午夜的练习归入评分当天。

到期图按当前下一次到期日期统计，不预测以后的反复练习次数，不按每日限额截断；包括学习与重学阶段。未学习、暂停、待确认、移出范围内容排除，已搁置内容归入恢复日。今日剩余包括今天稍后才到具体时间的内容。

保留率是自评的延迟回忆通过率：距上次练习至少 24 小时、当天首次有效评分才计入。重来为忘记，其他三个评分为记得；首次新学、短时间重复和撤销评分排除。旧记录只能在上次排程可准确还原时参与，无法确认的记录数量会显示；无样本显示“—”。笔记自评不代表整篇知识已完全掌握。

热力图显示当前统计范围最近 365 天的有效评分次数，同项当天评分三次计三次。“额外复习”计入；撤销会扣回原评分日期，创建／暂停／重置不计入。全部范围保留已删除或移出范围内容的历史。分组及标签历史按评分时归属计算，旧记录缺少归属时按现有标签判断。同步日志按事件 ID 去重。点击或悬停日期查看次数，手机可横向查看全年，默认定位最近日期；设置中仍可分别隐藏两种模式的热力图。

## 数据与同步

排程数据默认写入 Vault 根目录的 `复习中心数据/`：

```text
复习中心数据/
  records/   # 每来源笔记一份排程快照
  history/   # 每设备、每次插件运行独立的追加历史
  exports/   # 备份与导出的 CSV
  migrations/ # 旧章节备份与目录迁移记录
  operations/ # 标签修改与重新排程的可恢复记录和原文
```

在 Obsidian Sync 中开启“同步其他文件类型”。复习组与显示设置保存在插件 `data.json`；若需要同步配置，还需同步相应插件设置。当前会话保存在本机，排程和历史通过数据目录同步。

正文解析缓存保存在每台设备自己的 IndexedDB 中，不进入 Vault，也不参与同步。清空缓存只会让下次整理重新解析，不会删除评分、排程或历史。

如果出现无法开始复习、移动笔记后路径不正确或复习清单异常，可进入“设置 → 渐进式复习 → 数据与备份”，点击“修复知识库”。它会先生成 `pre-repair` 完整复习数据备份，再重新读取原文、核对路径和标签、重建本插件的解析索引，并清理失效的复习标签页引用。修复期间暂停评分和其他批量写入；评分与排程不重置，暂时找不到的原文保留记录供后续重新连接。页面会显示进度、待核对数量和备份路径；索引尚未就绪、备份失败或数据无法读取时会明确提示，等待同步完成或核对备份后可重试。

支持完整 JSON 备份／恢复以及有效评分 CSV 导出。v4 备份包含复习组、预设、节点覆盖、搁置和用时历史；兼容 v1／v2／v3 备份，v1 设置会转换为空标签组。每次恢复前另存 `pre-restore` 备份；恢复使用当前数据目录。

在设置中输入知识库内相对路径，如 `学习数据/复习中心`，也可选择已有空文件夹。输入时不切换；点击“应用并迁移”才开始。迁移期间暂停扫描、评分及其他批量写入，等待在途写入完成，备份后复制并核对全部复习数据，最后切换目录并重新读取。目标必须为空或不存在，新旧目录不能互相包含，旧目录保留为备份。失败继续使用原路径；中断后再次填写同一目标并点击应用即可继续。若中断前路径已保存，重启后会从已核对的新目录读取。
