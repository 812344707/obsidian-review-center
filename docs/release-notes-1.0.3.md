# 1.0.3 · Extra 答后补充修复

修复 `Extra:` 被当作题面或答案正文显示的问题。复习正面现在隐藏整个补充字段；点击“显示答案”后，只在答案下方显示补充内容，不显示 `Extra:` 字样。

标准 Basic/Cloze、正文 `Q:` / `A:`、正文独立挖空以及 `[!review]` 问答/挖空采用同一规则。补充支持 Markdown，补充中的挖空语法不会生成额外卡片。

[下载完整安装包](https://github.com/812344707/obsidian-review-center/releases/download/1.0.3/review-center-1.0.3.zip)。最低要求 Obsidian 1.13.0；升级保留现有 `data.json`、稳定卡片编号、评分与排程。

279 项自动测试和独立 Obsidian 临时库的 89 条原生界面断言通过。真实移动设备与跨设备并发同步仍待验证。[升级说明](1.0.3-upgrade.md) · [验证记录](1.0.3-validation.md)。
