# 渐进式复习 · Progressive Review

面向手机使用的 Obsidian 复习插件：在原文中复习整篇笔记，直接在正文或 `[!review]` 提示块中制作问答与挖空卡片，使用 FSRS 安排下一次复习。

当前版本：**0.4.4 测试版**，最低支持 Obsidian 1.13.0。插件内部 ID 仍为 `review-center`，升级会继续使用原设置和复习数据。

## 正文制卡与稳定编号（当前开发版）

- 笔记复习底栏：**制卡**可选标准问答或标准挖空模板；**问答**插入 `Q:` / `A:`；选中文字后点**填空**，直接生成 `{{c1::选中文字}}`。旧 `[!review]` 和 `问::` / `答::` 原样兼容。
- 正文内置标准 `START/END`、简写问答和独立挖空三种规则，不需要配置正则。标准块可写多段答案和 `Extra`；问答内容中的挖空标记不会重复生成卡片。
- 首次整理会为正文卡写入隐藏的 `review-center-id`。文件改名、移动、重复整理和重建本机解析缓存都沿用原卡片 ID、排程与历史；已有 `^rv-...` 和 Anki ID 不改写。
- 整理数据使用按知识库隔离的 IndexedDB 解析缓存。缓存只保存全文 SHA-256、解析版本、识别设置和解析结果；评分与排程仍以 Vault 内的正式记录为准。开始复习不扫描全库，评分前仍核对当前来源和最新历史。
- 设置分为**笔记识别**和**卡片识别**，各组独立配置文件夹、标签及“是／否／包含／排除”，条件可组合为“全部满足”或“任意满足”。旧标签范围继续有效；保存后点**整理数据**更新清单。
- **需要处理**只保留尚未解决的问题，提供原因、处理办法和原文定位；已按确定规则合并的同步冲突只留在诊断计数中。
- 主页操作顺序：**整理数据 → 开始 → 统计 → 设置**。

实现与隔离环境结果见 [正文制卡、稳定编号与性能验证](docs/body-cards-stable-ids-validation-2026-09-05.md)。

详见 [0.4.4 使用与升级说明](docs/0.4.4-upgrade.md) 和 [验证记录](docs/0.4.4-validation.md)。

## 安装与升级

解压 `review-center-0.4.4.zip`，把其中 `review-center/` 文件夹放入 Vault 的 `.obsidian/plugins/`，然后启用“渐进式复习”。升级时覆盖 `main.js`、`manifest.json`、`styles.css`，保留已有 `data.json`，重新加载插件。

从 0.2.0 升级时，现有复习组和评分规则保持不变。扫描会将已管理笔记的旧复习章节转换为折叠块，包括暂时移出范围的笔记；以后重新纳入的旧笔记也会先转换。旧标题配置仅用于迁移。纯格式转换不出现“新卡”或“内容已修改”提示。

转换前，排程与历史备份写入 `exports/pre-callout-migration-*.json`，每篇原笔记及对应排程写入 `migrations/callouts/`。重复标题、标识冲突、无法对应内容或备份失败时，不修改该笔记，保留进度，并在首页列出问题。修正后重新扫描即可继续，已转换的笔记不会重复转换。升级详情见 [0.3.0 升级说明](docs/0.3.0-upgrade.md)。

从 0.1.0 升级时，插件先将旧设置、排程和历史备份到数据目录的 `exports/pre-tags-migration-*.json`，随后停止使用文件夹范围。默认笔记组和卡片组继承旧限额与目标记忆率，但标签集为空：配置标签后才恢复纳入。升级不会给笔记补标签，不会清除旧进度。

## 设置复习范围

1. 打开“设置 → 渐进式复习”，在“复习分组”中管理组名称。
2. 分别进入“笔记识别”或“卡片识别”，选择复习组、添加文件夹或标签条件，点击“保存”。例如全部满足：文件夹包含“学习”，标签排除“草稿”。使用标签条件时，可在笔记属性或正文中添加标签。
3. 在主页点击“整理数据”，选择一行复习组或子标签，再点击“开始”；同一范围有未完成会话时，再点“开始”即可接着复习。

“是／否”精确匹配笔记所在文件夹或完整标签；“包含／排除”包括子文件夹、子标签。例如“文件夹是学习”不含“学习/伤寒”，“文件夹包含学习”则包含。根目录用 `/`。空条件不纳入任何笔记；只有否定条件时，从全库中排除对应范围。笔记范围不会自动用于卡片范围；命中卡片范围的文章可直接使用下文任一制卡格式。

例如，笔记包含：

```yaml
tags:
  - 复习/笔记/伤寒
  - 复习/卡片/伤寒
```

笔记组可选择 `#复习/笔记`，卡片组可选择 `#复习/卡片`。卡片继承来源笔记的全部标签；同一篇笔记可以只进入笔记复习、只进入卡片复习，或同时进入两者。

每组多个标签匹配**任意一个**；父标签包含所有下级标签，匹配不区分大小写。`#中医` 匹配 `#中医/伤寒`，不会匹配 `#中医基础`。同一内容命中多个组时，更具体的标签优先；层级相同则按设置中的组顺序决定，每个复习项只保留一份排程。

支持新增、复制、上移、下移、删除复习组。删除组、移除笔记标签或标签集留空会使内容退出范围，但保留历史和排程；重新匹配后继续使用。笔记改名、换文件夹不会改变其身份和复习进度。

这些操作集中在“管理复习组…”中。输入标签时可从下拉框选择，桌面支持方向键和回车，手机可直接点选；也可输入新标签后点“添加”或按回车。属性标签、正文标签及其父级都会出现在建议中。切换复习类型或组会保留草稿，“还原修改”恢复已保存内容。

### 批量添加标签

从设置页或命令面板打开“渐进式复习：批量添加标签”。按文件夹筛选时默认包含子文件夹，可关闭；按标签集筛选时可选“满足任意一个”或“同时满足全部”，两者均包含子标签。

填写额外标签后点击“预览匹配文章”，检查文件清单和每篇将新增的标签，取消不需要的文件，再执行。仅补充笔记属性中的 `tags`，已有属性标签或正文标签不会重复添加，正文保留；属性的排版可能重新格式化。插件数据目录自动排除。预览后发生变化、属性无法解析或写入失败的文件会跳过并报告，重新预览后可重试。完成后自动刷新复习数量；新纳入的文章会正常补充 `review_id` 和卡片稳定标识。

## 复习参数

| 参数 | 新建笔记组 | 新建卡片组 |
| --- | --- | --- |
| 每日新内容 | 1 篇 | 10 张 |
| 每日到期复习 | 10 篇 | 100 张 |
| 目标记忆率 | 85% | 90% |
| 学习步长 | `1m 10m` | `1m 10m` |
| 重学步长 | `10m` | `10m` |
| 最大间隔 | 36500 天 | 36500 天 |

目标记忆率可设为 70%–99%，更高通常意味着更多复习。步长用空格分隔，`m` 为分钟，`h` 为小时，每步至少 1 分钟且小于一天；留空交给 FSRS 安排。新参数默认从下次评分起生效；明确开启“更改时重新排程”才会预览并调整已有到期日期。

每日限额按设备当地自然日（午夜换日）、复习类型和复习组累计，重新开始或重启不会重置。新内容与到期复习分别计额，同项当天多次练习只占一次对应额度，按当天首次有效评分时的组记账；各组额度独立；子标签可选择是否受顶层组总限额约束。首页显示当前限额内可练习数量，已搁置和尚未到时间的内容不计入。

提供“重来、困难、良好、简单”四档评分与间隔预览。短期练习到时后，尚未关闭的复习会话会自动补入到期内容（最多约 15 秒刷新）；也可在首页点击“开始”。支持撤销最近评分、退出后自动续接、暂停、恢复和重置。

## 制作卡片

文章先要命中卡片复习组的文件夹或标签范围。正文按“标准块 → 简写问答 → 独立挖空”的顺序识别；属性、注释、代码示例和其他 Callout 不制卡。整篇文章是否进入笔记复习，只由笔记复习组决定。

简写问答适合单段答案，空行结束答案：

```markdown
Q: FSRS 的作用是什么？
A: 根据每次评分估计记忆状态，并安排下一次复习。
```

需要多段答案时使用标准问答。首字段 `Front:` 可以省略：

```markdown
START
Basic
Front: FSRS 的作用是什么？
Back: 根据每次评分估计记忆状态。

- 再安排下一次复习
- 答案可包含 Markdown
END
```

独立正文段落中的挖空可直接识别；相同 `cN` 同时隐藏和揭示，不同编号生成不同卡片：

```markdown
FSRS 使用 {{c1::稳定性::记忆强度}}、{{c2::难度}} 和 {{c3::可提取性}} 描述记忆。
```

标准挖空可以附加答后补充，首字段 `Text:` 可以省略：

```markdown
START
Cloze
Text: FSRS 使用 {{c1::稳定性}} 描述记忆强度。
Extra: 稳定性越高，遗忘速度通常越慢。
END
```

旧笔记继续支持 `[!review]`，不会批量改写：

```markdown
> [!review]- 核心概念
> 问:: FSRS 的作用是什么？
> 答::
> 根据每次评分估计记忆状态，并安排下一次复习。
>
> - 答案可包含多段内容
> - 支持列表、链接、图片和其他 Markdown

正文可继续写在复习块之间。

> [!review]- 挖空
> FSRS 使用 {{c1::稳定性}}、{{c2::难度}} 和 {{c3::可提取性}} 描述记忆。
```

旧问答答案延续到下一张 `问::` 或下一个子标题。旧问答后要写独立挖空时，请另起子标题。正文简写问答中的 `{{cN::...}}` 属于问答内容，不会再生成挖空卡；要同时制作两类题，请将挖空另起独立段落或标准块。

同一个块内可放多张问答或挖空卡片；多个独立 Callout 之间留一行不带 `>` 的空行。普通正文、其他类型 Callout、代码示例、注释和嵌套块不会单独制卡。

插件在纳入的笔记属性中维护 `review_id`。旧 Callout 卡继续使用 `^rv-...`；正文卡使用隐藏的 `<!--review-center-id: rv-...-->`。请保留这些标识。每个挖空由稳定 ID 与 `cN` 共同确定；新增编号不会改变已有卡片。内容修改后可选择保留或重置进度；明确删除后退出队列并由历史保留删除记录。编号重复或归属不明时暂停相关处理，不按相似内容猜测绑定。

## 统计与热力图

主页点击“统计”进入独立页面，初始查看所选组／标签范围，可切换为全部复习组和另一种复习模式。统计筛选、时间切换不改变主页选择、复习参数和进度；返回后恢复主页的树形位置。

今日概览与近期趋势按每天首次有效评分区分新学、复习，同项当天反复练习只计一项。用时合计有记录的部分，未记录用时明确标注；未评分的阅读时间不计入，跨午夜的练习归入评分当天。

到期图按当前下一次到期日期统计，不预测以后的反复练习次数，不按每日限额截断；包括学习与重学阶段。未学习、暂停、待确认、移出范围内容排除，已搁置内容归入恢复日。今日剩余包括今天稍后才到具体时间的内容。

保留率是自评的延迟回忆通过率：距上次练习至少 24 小时、当天首次有效评分才计入。重来为忘记，其他三个评分为记得；首次新学、短时间重复和撤销评分排除。旧记录只能在上次排程可准确还原时参与，无法确认的记录数量会显示；无样本显示“—”。笔记自评不代表整篇知识已完全掌握。

热力图显示当前统计范围最近 365 天的有效评分次数，同项当天评分三次计三次。“额外复习”计入；撤销会扣回原评分日期，创建／暂停／重置不计入。全部范围保留已删除或移出范围内容的历史。分组及标签历史按评分时归属计算，旧记录缺少归属时按现有标签判断。同步日志按事件 ID 去重。点击或悬停日期查看次数，手机可横向查看全年，默认定位最近日期；设置中仍可分别隐藏两种模式的热力图。

## 数据与同步

排程数据默认写入 Vault 根目录的 `复习中心数据/`：

```text
复习中心数据/
  records/   # 每来源笔记一份排程快照
  history/   # 每设备、每次插件运行独立的追加历史
  exports/   # 备份与导出的 CSV
  migrations/ # 旧章节备份与目录迁移记录
  operations/ # 标签修改与重新排程的可恢复记录和原文
```

在 Obsidian Sync 中开启“同步其他文件类型”。复习组与显示设置保存在插件 `data.json`；若需要同步配置，还需同步相应插件设置。当前会话保存在本机，排程和历史通过数据目录同步。

正文解析缓存保存在每台设备自己的 IndexedDB 中，不进入 Vault，也不参与同步。清空缓存只会让下次整理重新解析，不会删除评分、排程或历史。

支持完整 JSON 备份／恢复以及有效评分 CSV 导出。v4 备份包含复习组、预设、节点覆盖、搁置和用时历史；兼容 v1／v2／v3 备份，v1 设置会转换为空标签组。每次恢复前另存 `pre-restore` 备份；恢复使用当前数据目录。

在设置中输入知识库内相对路径，如 `学习数据/复习中心`，也可选择已有空文件夹。输入时不切换；点击“应用并迁移”才开始。迁移期间暂停扫描、评分及其他批量写入，等待在途写入完成，备份后复制并核对全部复习数据，最后切换目录并重新读取。目标必须为空或不存在，新旧目录不能互相包含，旧目录保留为备份。失败继续使用原路径；中断后再次填写同一目标并点击应用即可继续。若中断前路径已保存，重启后会从已核对的新目录读取。
