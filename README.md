# 复习中心

面向手机使用的 Obsidian 复习插件：在原文中复习整篇笔记，在笔记末尾手写问答与挖空卡片，使用 FSRS 安排下一次复习。

当前版本：**0.2.0 测试版**，最低支持 Obsidian 1.13.0。

## 0.2.0 更新

- 使用多层标签指定范围，分别管理笔记与卡片复习组。
- 每组独立设置每日限额、目标记忆率、学习／重学步长和最大间隔。
- 首页可选择全部组或单组，分别显示笔记和卡片热力图。
- 蓝紫色入口与问答／挖空卡样式，适配明暗主题和手机布局。
- 修复每日限额跨会话重复放出额度、重载时提前跳过当前复习项的问题。

## 安装与升级

解压 `review-center-0.2.0.zip`，把其中 `review-center/` 文件夹放入 Vault 的 `.obsidian/plugins/`，然后启用“复习中心”。升级时覆盖 `main.js`、`manifest.json`、`styles.css`，保留已有 `data.json`，重新加载插件。

从 0.1.0 升级时，插件先将旧设置、排程和历史备份到数据目录的 `exports/pre-tags-migration-*.json`，随后停止使用文件夹范围。默认笔记组和卡片组继承旧限额与目标记忆率，但标签集为空：配置标签后才恢复纳入。升级不会给笔记补标签，不会清除旧进度。

## 设置复习范围

1. 在需要复习的笔记属性中添加 `tags`，或在正文写 Obsidian 标签。
2. 打开“设置 → 复习中心”，分别展开笔记复习组、卡片复习组，填写标签，点击本组“保存”。
3. 在复习中心选择全部组或指定组，开始复习。

例如，笔记包含：

```yaml
tags:
  - 复习/笔记/伤寒
  - 复习/卡片/伤寒
```

笔记组可选择 `#复习/笔记`，卡片组可选择 `#复习/卡片`。卡片继承来源笔记的全部标签；同一篇笔记可以只进入笔记复习、只进入卡片复习，或同时进入两者。

每组多个标签匹配**任意一个**；父标签包含所有下级标签，匹配不区分大小写。`#中医` 匹配 `#中医/伤寒`，不会匹配 `#中医基础`。同一内容命中多个组时，更具体的标签优先；层级相同则按设置中的组顺序决定，每个复习项只保留一份排程。

支持新增、复制、上移、下移、删除复习组。删除组、移除笔记标签或标签集留空会使内容退出范围，但保留历史和排程；重新匹配后继续使用。笔记改名、换文件夹不会改变其身份和复习进度。

## 复习参数

| 参数 | 新建笔记组 | 新建卡片组 |
| --- | --- | --- |
| 每日新内容 | 1 篇 | 10 张 |
| 每日到期复习 | 10 篇 | 100 张 |
| 目标记忆率 | 85% | 90% |
| 学习步长 | `1m 10m` | `1m 10m` |
| 重学步长 | `10m` | `10m` |
| 最大间隔 | 36500 天 | 36500 天 |

目标记忆率可设为 70%–99%，更高通常意味着更多复习。步长用空格分隔，`m` 为分钟，`h` 为小时，每步至少 1 分钟且小于一天；留空交给 FSRS 安排。新参数从下次评分起生效，不重排已有到期日期。

每日限额按设备当地自然日（午夜换日）、复习类型和复习组累计，重新开始或重启不会重置。新内容与到期复习分别计额，同项当天多次练习只占一次对应额度，按当天首次有效评分时的组记账；各组额度独立，不额外叠加父组总限额。首页显示当前限额内可练习数量，“额外复习”可以超限，评分仍计入历史和当天完成量。

提供“重来、困难、良好、简单”四档评分与间隔预览。短期练习到时后，尚未关闭的复习会话会自动补入到期内容（最多约 15 秒刷新）；也可在首页重新开始。支持撤销最近评分、退出与继续、暂停、恢复和重置。

## 制作卡片

在笔记末尾手动建立 `## 复习`，标题文字和层级可在设置中修改。插件只解析命中卡片复习组的笔记中的这个章节。

```markdown
## 复习

### 核心概念

问:: FSRS 的作用是什么？
答::
根据每次评分估计记忆状态，并安排下一次复习。

- 答案可包含多段内容
- 支持列表、链接、图片和其他 Markdown

### 挖空

FSRS 使用 {{c1::稳定性}}、{{c2::难度}} 和 {{c3::可提取性}} 描述记忆。
```

问答答案延续到下一张 `问::` 或下一个子标题。问答后要写独立挖空时，请另起子标题。同一挖空编号一起隐藏，不同编号生成不同卡片；支持 `{{c1::答案::提示}}`。

插件在纳入的笔记属性中维护 `review_id`，并为卡片补充 `^rv-...` 稳定块 ID。请保留这些标识。卡片内容修改后可选择保留或重置进度；卡片块删除后移除对应排程。单张卡片跨笔记剪切不属于本版的进度保持范围。

## 热力图

主页分别显示笔记、卡片最近 365 天的有效评分次数，同项当天评分三次计三次。“额外复习”计入，撤销会扣回原评分日期，创建／暂停／重置不计入。

热力图包含已有历史，不随标签范围变化；来源笔记删除后历史依然保留。同步重复日志按事件 ID 去重。点击或悬停日期查看次数，手机可横向查看全年，默认定位最近日期；可在设置中分别隐藏两张图。

## 数据与同步

排程数据默认写入 Vault 根目录的 `复习中心数据/`：

```text
复习中心数据/
  records/   # 每来源笔记一份排程快照
  history/   # 每设备、每次插件运行独立的追加历史
  exports/   # 备份与导出的 CSV
```

在 Obsidian Sync 中开启“同步其他文件类型”。复习组与显示设置保存在插件 `data.json`；若需要同步配置，还需同步相应插件设置。当前会话保存在本机，排程和历史通过数据目录同步。

支持完整 JSON 备份／恢复以及有效评分 CSV 导出。v2 备份包含复习组和显示设置；仍能恢复 v1 备份，并转换为空标签组。每次恢复前另存 `pre-restore` 备份；恢复使用当前数据目录。更改数据目录不会自动搬迁原数据，应先导出备份后在新目录恢复。
